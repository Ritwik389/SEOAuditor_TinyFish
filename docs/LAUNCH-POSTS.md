# LinkedIn draft

Can AI search tools actually read and understand your website?

I built SEOAuditor for the TinyFish × DTU workshop challenge to explore the gap between what a page says, what AI tools extract, and how it appears in search.

Give it a public URL and an optional search query. It uses TinyFish Search and Fetch to collect live evidence, then turns visibility and readability gaps into specific fixes.

Some features I added:

- An extraction-versus-discovery matrix: being readable and being discoverable are measured separately.
- Query coverage and verbatim evidence cards, so you can inspect the source behind a finding.
- Optional Browser and Agent checks for rendered content, FAQs and tabs, with visible Agent run status.
- Prioritized fixes, JSON evidence export, printable reports and browser-local history.
- No sign-in needed for the public demo.

A deep audit uses at least four TinyFish endpoints: Search, Fetch, Agent creation and Run Status. The project extends the original SeoAnalyzer UI and codebase.
